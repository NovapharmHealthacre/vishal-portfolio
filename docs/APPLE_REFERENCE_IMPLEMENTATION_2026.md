# Apple-reference portfolio forensic audit (9 October 2026)

## Reference and transformation
Apple.com was reviewed as a design reference. The site translates the principles of a compact persistent nav, typography-led hero, one message per section, generous whitespace, restrained blue CTAs, alternate light/dark panels, modular content cards, mobile-specific compositions, and accessible reduced motion.
All graphics and written content remain original to the portfolio; no Apple trademarks, copyrighted images, font files or source assets are reused.

## Repository and live-site findings
- Production is generated by a Node 22 static-site build with server-rendered HTML.
- Four style sources had accumulated before this change; the homepage and subpages did not share a completely consistent navigation geometry.
- Real NASA imagery and attribution, the portrait, essays, public evidence, registered company links, and historical URLs should be preserved.
- Existing SEO foundation includes canonical tags, hreflang, sitemap, robots, Person/ProfilePage/Organization and Article schema, feeds, image variants, social cards and an ownership verification HTML file.
- Public fetch of robots.txt and sitemap.xml could not be independently completed in this review; source and generation tests remain inspectable.
- Connected GSC Wizard returned no Search Console properties as of the review; a verification HTML file does not prove current verified Google access.
- A Google Knowledge Panel was not independently confirmed; a panel cannot be created through structured data alone.

## Pull request contents
- public/assets/product-grade-2026.css is the single documented last-mile visual design system.
- Build bundles product design into the single site.css; route-specific NASA CSS is loaded ahead of the final product design.
- Performance checks now cover BOTH CSS payloads and the complete initial-transfer estimate.
- Regression tests pin style load order and canonical/structured-identity crawlability.
- No old URLs, factual claims, published articles, site-verification files or schema have been removed.
