# Ask Vishal’s Work — Retired system record

Status: **Retired**

Reviewed: 3 October 2026

The former source-first browser assistant is no longer part of the public website.

## Removed components

- `public/assets/founder-ai.js`
- `public/assets/founder-knowledge.json`
- site-wide Ask Vishal navigation/dialog UI
- dedicated browser-assistant acceptance workflow
- Gallery-linked assistant entry points

## Replacement discovery architecture

The public founder record now relies on:

- canonical HTML biography and facts pages;
- Person/ProfilePage/Organization JSON-LD;
- `facts.json`;
- `llms.txt`;
- XML sitemap;
- RSS and JSON Feed;
- publisher-hosted evidence and independent public records.

## Reintroduction policy

Do not recreate the retired assistant from this historical record. A future assistant would be a new product with separate requirements, security/privacy review, accessibility testing and owner approval.
